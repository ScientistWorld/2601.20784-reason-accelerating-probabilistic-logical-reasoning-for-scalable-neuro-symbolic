# Scientist Constraints

## Data

Use the deterministic benchmark generated by `data/generate_benchmarks.py` with the default seed and sizes. Do not add external datasets or tune on a different generated distribution when reporting `scoring/scores.json`.

## Evaluation

Use `scripts/evaluate.sh` unchanged for scoring. The evaluator must read candidate artifacts and must not call candidate method code.

## Resource Accounting

Report machine-independent graph metrics only. Do not replace `memory_reduction_pct` with wall-clock speed, GPU time, or hardware-specific throughput.

## Problem Scope

A valid improvement must operate on logical/probabilistic reasoning graph transformations. It must not replace the task with a neural predictor or hardcode outputs for the generated benchmark.

## Compliance Checklist

- [ ] Default generated benchmark is used.
- [ ] `scripts/evaluate.sh` is unchanged.
- [ ] Scores are computed from artifacts, not hardcoded.
- [ ] Metrics remain graph-size and fidelity metrics, not wall-clock timing.
- [ ] The method transforms reasoning graphs rather than training a surrogate predictor.
